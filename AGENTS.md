# Holo

Holo is a macOS invention studio built around one central idea and four perspectives. Preserve the full-screen spatial stage, compact bottom prompt, stable focal point, and smoothly orbiting station transitions. Project identity lives at the top left, clear of native window controls. The optional Activity panel stays open on the right without blocking the scene or prompt. Avoid persistent toolbars and expanded cockpits. Production state must come from real projects and tool results; sample content and transient concept sketches must be explicitly identified.

Use TypeScript, React, React Three Fiber, Electron and a loopback Node service. Shared contracts are in shared/types.ts. Project data belongs in the user's application-data directory, never the source repository. Keep generated artifacts tied to revisions, and distinguish conceptual proposals from supplier-confirmed or physically validated output.

Run npm run check, npm test, npm run build and meaningful browser/native interaction checks before delivery. Independent creative and UX review is explicitly requested; record findings and fixes in docs. Never commit credentials, personal project files, authentication state, or generated private artifacts.
